# Search Engine - Поисковый движок

## Описание проекта

Реализация системы поиска по корпоративному порталу компании "АйТиБокс". Это консольное приложение, осуществляющее поиск по набору документов с использованием инвертированного индекса и ранжирования результатов по релевантности.

## Стек технологий

- **Язык**: C++17
- **Библиотеки**: 
  - nlohmann/json - для работы с JSON
  - Google Test - для модульного тестирования
- **Сборка**: CMake
- **Многопоточность**: std::thread для параллельной индексации

## Функциональность

- 📁 Индексация документов в многопоточном режиме
- 🔍 Поиск по инвертированному индексу
- 📊 Ранжирование результатов по релевантности
- ⚙️ Настройка через JSON-конфиги
- 🧪 Полное покрытие unit-тестами
- 🚀 Обработка больших объемов данных

## Требования

- Компилятор с поддержкой C++17 (GCC, Clang, MSVC)
- CMake 3.14+
- Интернет-соединение (для загрузки зависимостей)

## Быстрый старт

### Сборка проекта

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd search_engine

# Создание папки для сборки
mkdir build && cd build

# Конфигурация проекта
cmake ..

# Сборка
cmake --build .

# Или для сборки в Debug режиме
cmake --build . --config Debug
